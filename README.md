# URL Worker

A Django-based URL management system that allows users to shorten URLs, retrieve the original URL, and manage links with built-in authentication.

## Features

- Shorten any URL
- Create custom aliases for shortened URLs
- Retrieve the original URL from a shortened link
- Check URL health
- Generate QR codes for shortened URLs
- User authentication

## Tech Stack

- Python 3.14
- Django
- Sqlite3

## How to Run

1. Clone the repository
2. Install dependencies with requirements.txt
3. Open browser and visit localhost:8000

## Future Improvements

- URL analytics
- Rate limiting
- Mobile-responsive UI
- Private URLs
